# Pico Firmware Generator

Graphical and CI-based firmware generator for Raspberry Pi Pico / CircuitPython.

Planned outputs:

- validated firmware configuration
- custom CircuitPython UF2
- `boot.py`
- reproducible build manifest and SHA-256 checksums
- packaged Windows x64 desktop application

> [!WARNING]
> The example VID/PID `0x239A / 0x80F4` belongs to Adafruit. It is suitable only where Adafruit's terms permit it; production devices require a legally assigned VID/PID.

No credentials or personal access tokens belong in this repository.
