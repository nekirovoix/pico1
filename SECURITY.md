# Security

- Never commit GitHub personal access tokens, passwords, signing keys, or other credentials.
- If a token is pasted into chat, an issue, a commit, or a log, revoke it immediately and create a replacement through GitHub's secure settings.
- Verify `SHA256SUMS.txt` before flashing an artifact.
- The generated drive-hiding behavior is a convenience feature. It is **not** encryption, secure boot, or protection against physical access.
- `0x239A / 0x80F4` is an example Adafruit VID/PID. Production devices require a VID/PID that you are legally permitted to use.
