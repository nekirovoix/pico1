# تولیدکننده فریمور Raspberry Pi Pico

این مخزن فریمور سفارشی CircuitPython و برنامه Windows x64 را در GitHub Actions می‌سازد؛ بنابراین برای ساخت معمول نیازی به WSL روی رایانه کاربر نیست.

## خروجی‌ها

- فایل UF2 سفارشی
- `boot.py`
- تنظیمات نهایی و manifest قابل ممیزی
- `SHA256SUMS.txt`
- برنامه Windows x64
- بسته سورس در Release

## تنظیمات

فایل `config/default.json` شامل نسخه CircuitPython، برد مبدأ/مقصد، نام سازنده و محصول USB، VID/PID، پیشوند سریال، برچسب درایو، پین تعمیر، حالت نمایش درایو و زبان است.

مقادیر توسط `generator/generate.py` بررسی می‌شوند. رشته‌های USB باید ASCII چاپ‌پذیر باشند، VID/PID باید دقیقاً چهار رقم هگز داشته باشند و نام درایو باید حداکثر ۱۱ نویسه بزرگ باشد.

حالت‌های درایو:

- `maintenance`: در حالت عادی درایو مخفی است؛ با اتصال پین تعمیر به GND هنگام reset نمایان می‌شود.
- `always`: درایو همیشه نمایان است.
- `hidden`: درایو همیشه مخفی است؛ بازیابی همچنان با BOOTSEL و `RPI-RP2` ممکن است.

## ساخت ابری

1. تنظیمات را در فایلی داخل پوشه `config/` قرار دهید.
2. به تب **Actions** بروید.
3. Workflow با نام **Build firmware and Windows app** را اجرا کنید.
4. مسیر فایل تنظیمات را وارد کنید.
5. پس از پایان، artifactهای firmware و Windows را دانلود کنید.

برای انتشار، یک tag مانند `v1.2.0` push کنید یا هنگام اجرای دستی `release_tag` را وارد کنید.

## آماده‌سازی Pico

- در حالت BOOTSEL فقط درایو دقیق `RPI-RP2` برای کپی UF2 پذیرفته می‌شود.
- برنامه قبل از کپی UF2، SHA256 آن را بررسی می‌کند.
- `boot.py` فقط روی `CIRCUITPY`، `CLASSROOM` یا برچسب پیکربندی‌شده نصب می‌شود.
- فایل `boot.py` قبلی فقط یک بار با نام `boot.py.before-classroom` پشتیبان‌گیری می‌شود.
- برنامه هیچ درایوی را فرمت نمی‌کند و حذف عمومی فایل انجام نمی‌دهد.

## هشدار VID/PID

VID/PID پیش‌فرض `0x239A / 0x80F4` متعلق به Adafruit است. استفاده در محصول نهایی نیازمند VID/PID قانونی متعلق به شما یا مجوز معتبر است.

پنهان‌کردن درایو، رمزنگاری یا Secure Boot محسوب نمی‌شود.
